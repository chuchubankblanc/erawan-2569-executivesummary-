    ที่มาข้อมูลและการคัดเคส อ้างอิง

    ไฟล์ Data การออกเหตุ ศูนย์เอราวัณ ปีงบประมาณ 2569 (ฉบับเพิ่มอายุ เพศ CPR) แบ่งโซนตามเขตที่เกิดเหตุ (คอลัมน์ อำเภอ) ตามตาราง 50 เขต → 11 โซน ส่วนเขตจตุจักร บางกอกใหญ่ บางซื่อ บางบอน และวังทองหลาง แบ่งตามแขวง (คอลัมน์ ตำบล)

    นิยามตัวชี้วัด อ้างอิง
    Basic / Advance
    คอลัมน์ จัดหน่วยบริการระดับ = BLS / ALS
    อื่นๆ
    ML, CLS, FR และ ERB รวมกัน แสดงรายตัวในตารางหน่วย
    ไม่ระบุ
    เคสที่คอลัมน์ระดับหน่วยว่าง
    ชุดรหัสอาการ
    รวมคอลัมน์ L รหัส + M สี + N ระดับ เป็นชุดเดียว เช่น 25แดง2 = รหัส 25 สีแดง ระดับ 2 ถ้าขาดตัวใดตัวหนึ่งนับเป็น “ไม่ระบุ”
    กลุ่มอายุ (คอลัมน์ Q)
    เด็ก 0–14 ปี · ผู้ใหญ่ 15–59 ปี · ผู้สูงอายุ 60 ปีขึ้นไป · อายุ 0 หรือว่าง = ไม่ระบุ
    เพศ (คอลัมน์ R)
    ชาย / หญิง ตามที่บันทึก ค่า 0 หรือว่าง = ไม่ระบุ
    การทำ CPR (คอลัมน์ S)
    Yes = CPR · Yes,AED/DF = CPR + AED/DF · AED/DF = AED/DF อย่างเดียว · No = ไม่ได้ทำ
    ผลการดูแลรักษาเบื้องต้น (คอลัมน์ T)
    แจกแจงตามที่บันทึก รวมถึง “เสียชีวิต ณ จุดเกิดเหตุ” ค่าว่าง = ไม่มีบันทึก
    โรงพยาบาลปลายทาง (คอลัมน์ U)
    ชื่อห้องฉุกเฉินที่นำส่ง ค่า 0 หรือว่าง = ไม่ได้นำส่ง / ไม่มีบันทึก
    เขต
    เขตที่เกิดเหตุ ไม่ใช่เขตที่ตั้งของหน่วย
    ข้อควรระวังของข้อมูล อ้างอิง

    อายุและเพศมีค่า 0 หรือว่างจำนวนหนึ่ง ซึ่งนับเป็น “ไม่ระบุ” สัดส่วนกลุ่มอายุและเพศจึงคิดจากเคสทั้งหมด รวมกลุ่มไม่ระบุ

    “ไม่ได้นำส่ง / ไม่มีบันทึก” รวมทั้งเคสที่ไม่ได้นำส่งจริงและเคสที่ไม่ได้กรอกชื่อโรงพยาบาล แยกจากกันไม่ได้ในไฟล์นี้

    เขตจตุจักร บางกอกใหญ่ บางซื่อ บางบอน วังทองหลาง อยู่สองโซน แต่ละโซนนับเฉพาะแขวงของตัวเอง

    กลุ่มหน่วย (เอราวัณ / โรงพยาบาล / มูลนิธิและกู้ชีพ) จัดจากชื่อหน่วย ไม่มีคอลัมน์นี้ในไฟล์

    ไฟล์ไม่มีชื่ออาการของแต่ละรหัส และไม่มีชื่อหรือเลขประจำตัวผู้ป่วย

    โหลดข้อมูลไม่สำเร็จ
